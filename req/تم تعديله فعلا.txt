## الفكرة الأساسية

```
كل سوق = 3 APIs + قائمتان

API المتابعة → يشوف الأسعار لحظياً
API التحكم → يدخل ويخرج صفقات
API البيانات القديمة → للـ Backtesting

القائمة البيضاء → يتداول فيها
قائمة القياديين → يراقبها فقط لمعرفة الاتجاه

الصقر لا يشوف أي عملة/سهم خارج القائمتين
```

## قاعدة البيانات

```sql
-- جدول الأسواق
CREATE TABLE markets (
    id UUID PRIMARY KEY,
    name TEXT NOT NULL,
    type TEXT NOT NULL CHECK (type IN ('crypto', 'stocks', 'forex')),
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    user_id UUID REFERENCES profiles(id)
);

-- جدول API Keys
CREATE TABLE market_apis (
    id UUID PRIMARY KEY,
    market_id UUID REFERENCES markets(id),
    
    -- API المتابعة (URL ثابت في الكود)
    watch_api_key TEXT,
    watch_api_secret TEXT,
    
    -- API التحكم (URL ثابت في الكود)
    control_api_key TEXT,
    control_api_secret TEXT,
    
    -- API البيانات القديمة (URL ثابت في الكود)
    historical_api_key TEXT,
    
    last_tested_at TIMESTAMPTZ,
    is_connected BOOLEAN DEFAULT FALSE,
    user_id UUID REFERENCES profiles(id)
);

-- القائمة البيضاء (يتداول)
CREATE TABLE whitelist (
    id UUID PRIMARY KEY,
    market_id UUID REFERENCES markets(id),
    symbol TEXT NOT NULL,
    symbol_name TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    added_by UUID REFERENCES profiles(id),
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- قائمة القياديين (يراقب الاتجاه فقط)
CREATE TABLE market_leaders (
    id UUID PRIMARY KEY,
    market_id UUID REFERENCES markets(id),
    symbol TEXT NOT NULL,
    symbol_name TEXT,
    reason TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    added_by UUID REFERENCES profiles(id),
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## القاعدة البرمجية

```python
def get_symbols_for_worker(market_id):
    """
    الصقر يشوف فقط هذين النوعين
    غيرهم = لا يوجد
    """
    # يتداول فيها
    tradeable = whitelist.get_active(market_id)
    
    # يراقب فقط لمعرفة الاتجاه
    leaders = market_leaders.get_active(market_id)
    direction_only = [s for s in leaders if s not in tradeable]
    
    return {
        "tradeable": tradeable,      # يدخل صفقات ✅
        "direction": direction_only  # يراقب فقط 👁️
    }

def can_trade(symbol, market_id):
    """هل يجوز التداول في هذا الزوج؟"""
    return symbol in whitelist.get_active(market_id)

def should_monitor(symbol, market_id):
    """هل يجوز مراقبة هذا الزوج لتحديد الاتجاه؟"""
    return symbol in market_leaders.get_active(market_id)
```

## مثال 1 — Binance (كريبتو)

```python
class BinanceMarket(BaseMarket):
    name = "Binance"
    type = "crypto"
    
    # URLs ثابتة في الكود — المستخدم يكتب Key و Secret فقط
    WATCH_URL = "wss://stream.binance.com:9443"
    CONTROL_URL = "https://api.binance.com"
    HISTORICAL_URL = "https://api.binance.com"
    
    async def get_price(self, symbol):
        # BTC/USDT → 42,350.50$
        response = await self.client.get(
            f"{self.CONTROL_URL}/api/v3/ticker/price",
            params={"symbol": symbol.replace("/", "")}
        )
        return float(response["price"])
    
    async def buy(self, symbol, amount):
        return await self.client.post(
            f"{self.CONTROL_URL}/api/v3/order",
            data={
                "symbol": symbol.replace("/", ""),
                "side": "BUY",
                "type": "MARKET",
                "quoteOrderQty": amount
            }
        )
    
    async def get_historical(self, symbol, start, end, timeframe="4h"):
        return await self.client.get(
            f"{self.HISTORICAL_URL}/api/v3/klines",
            params={
                "symbol": symbol.replace("/", ""),
                "interval": timeframe,
                "startTime": start,
                "endTime": end
            }
        )
    
    async def place_stop_loss(self, symbol, price):
        return await self.client.post(
            f"{self.CONTROL_URL}/api/v3/order",
            data={
                "symbol": symbol.replace("/", ""),
                "side": "SELL",
                "type": "STOP_LOSS_LIMIT",
                "stopPrice": price
            }
        )
```

```python
class BaseMarket:
    name: str
    type: str
    
    async def get_price(self, symbol: str) -> float:
        raise NotImplementedError
    
    async def watch_price(self, symbol: str, callback):
        raise NotImplementedError
    
    async def buy(self, symbol: str, amount: float) -> dict:
        raise NotImplementedError
    
    async def sell(self, symbol: str, amount: float) -> dict:
        raise NotImplementedError
    
    async def get_balance(self) -> float:
        raise NotImplementedError
    
    async def place_stop_loss(self, symbol: str, price: float):
        raise NotImplementedError
    
    async def get_historical(
        self, symbol: str,
        start: str, end: str,
        timeframe: str = "4h"
    ) -> pd.DataFrame:
        raise NotImplementedError
    
    async def test_connection(self) -> dict:
        results = {
            "watch": False,
            "control": False,
            "historical": False
        }
        try:
            await self.get_price("BTC/USDT")
            results["watch"] = True
        except: pass
        
        try:
            await self.get_balance()
            results["control"] = True
        except: pass
        
        try:
            await self.get_historical("BTC/USDT", "2024-01-01", "2024-01-02")
            results["historical"] = True
        except: pass
        
        return results
```

## كيف يستخدمه الموظف

```python
class Worker:
    market: BaseMarket
    
    async def scan(self):
        symbols = get_symbols_for_worker(self.market.id)
        
        # يتداول فقط في البيضاء
        for symbol in symbols["tradeable"]:
            price = await self.market.get_price(symbol)
            if self.should_enter(price):
                await self.market.buy(symbol, self.trade_size)
                await self.market.place_stop_loss(symbol, self.sl_price)
        
        # يراقب فقط القياديين لتحديد الاتجاه
        for symbol in symbols["direction"]:
            price = await self.market.get_price(symbol)
            self.update_market_direction(symbol, price)
```

## الفكرة الأساسية

```
كل صمام = طبقة حماية مستقلة
لو طبقة فشلت — الطبقة التالية تحمي
11 طبقة = صعب جداً تخترق الكل
```

---

## 1. فحص السوق كل 15 دقيقة

```
Python يفحص ATR + Bollinger + Volume
كل 15 دقيقة بدون توقف
        ↓
السوق متوتر؟ → يوقف المستقر ويشغّل المتوتر
السوق مستقر؟ → يوقف المتوتر ويشغّل المستقر
        ↓
ما تدخل صفقة في بيئة خاطئة
```

---


## 2. نظام الطبقتين

```
قبل كل صفقة:
الطبقة 1 (مجاني): Fear&Greed + CryptoPanic + BTC Dominance
لو فشل → ما يدخل ❌

لو نجح → الطبقة 2 (AI)
لو فشل → ما يدخل ❌

لو نجح → يدخل ✅
```

---

## 3. Backtesting 7 سنوات

```
قبل ما يشتغل أي موظف:
الاستراتيجية تُختبر على 7 سنوات تاريخية
Sharpe > 1 | Drawdown < 15% | Win Rate > 50%
        ↓
فشلت؟ → ما تُبنى موظفين ❌

نجحت؟ → تكمل للخطوة التالية ✅
```

---

## 4. Walk-Forward 3 سنوات

```
بعد Backtesting:
تُختبر على 3 سنوات جديدة ما شافتها
        ↓
فشلت؟ → ما تُبنى موظفين ❌
نجحت؟ → تكمل ✅
```

---

## 5. Paper Trading إلزامي

```
لا موظف حقيقي بدون موظف وهمي ناجح
        ↓
الموظف الوهمي يثبت نفسه أولاً
أنت تقرر متى يكفي
بعدين تضغط الترقية يدوياً

```

---

## 6. قاعدة 1% مخاطرة قصوى

```
مهما كانت الفرصة:
كل صفقة = 1% من رأس المال كحد أقصى

مثال:
رأس المال: 10,000$
أكبر خسارة في صفقة واحدة: 100$
        ↓
حتى لو خسرت 10 صفقات متتالية:
خسرت 1,000$ فقط (10%)
ما راح تفلس
```

---

## 7. Trailing Stop + Stop Loss ثابت

```
Trailing Stop (متحرك):

يشتغل لما الصقر شغّال
لو السعر ارتفع → وقف الخسارة يرتفع معه
يحمي الربح ✅

Stop Loss ثابت (على المنصة):
يشتغل حتى لو الصقر مات
محفوظ على Binance/Alpaca مباشرة
لو الإنترنت انقطع → المنصة تغلق ✅
```

---

## 8. سجل أسباب الفشل والإيقاف اليدوي

```
كل فشل يُسجّل:
"استراتيجية X فشلت — السبب: Drawdown عالي وقت الفيد"
        ↓
الاجتماع القادم يقرأ السجل:
"ممنوع تكرار هذه الأنماط"
        ↓
لا تتكرر نفس الأخطاء ✅

كل إيقاف يدوي يُسجّل:

"أوقفت موظف 1 — السبب: خبر طارئ"
المستشار والاجتماع يقرأون هذا لاحقاً
```

---

## 9. زر الطوارئ + زر الإيقاف

```
زر أصفر (إيقاف ناعم):
لا دخول صفقات جديدة
الموجودة تكمل للهدف أو وقف الخسارة
مثال: "أبي أراجع الأداء — لكن ما أبي أخسر الصفقات القائمة"

زر أحمر (إيقاف فوري):
يغلق كل الصفقات الحين بسعر السوق
حتى لو بخسارة
مثال: "خبر كارثي — اخرج الحين!"
```

---

## 10. موافقتك اليدوية

```
كل قرار مصيري يحتاج ضغطتك:

✅ اعتماد الاجتماع
✅ ترقية موظف للحقيقي
✅ اعتماد تبديل السوق
✅ قبول/رفض سحب خارجي

النظام لا يتصرف وحده في القرارات الكبيرة
```

---

## 11. نسخة احتياطية محلية للصفقات

```
كل صفقة تُحفظ:
أولاً: محلياً على السيرفر ✅
ثانياً: في Supabase ✅

لو Supabase تعطّل:
النسخة المحلية موجودة
لما Supabase يرجع → تُرفع تلقائياً
لا تضيع أي صفقة ✅
```

# كل تنبيهات تليجرام في الصقر

---

## للمستخدم (Owner)

### تنبيهات السوق:
```
⚠️ السوق تحوّل من مستقر إلى متوتر
تم التبديل — ردّ خلال 5 دقائق
✅ موافق | ❌ رفض | ⏹️ إيقاف الكل
في حالة عدم الرد يتحول تلقائي من متوتر الى مستقر والعكس
```

### تنبيهات الصفقات:
```
✅ دخول صفقة: [الموظف] اشترى [الزوج] بـ [السعر]

✅ خروج بربح: [الموظف] باع [الزوج] ربح [المبلغ]

❌ خروج بخسارة: [الموظف] باع [الزوج] خسر [المبلغ]

⚠️ تقليص سيولة:
[الموظف] | [الزوج]

المطلوب: X$ | الفعلي: Y$
السبب: سيولة منخفضة
الصفقات المتبقية: Z
```

### تنبيهات الاجتماع:
```
✅ جاهز
(بعد اكتمال الجلسة كاملاً)

❌ فشل Backtesting
السبب: Drawdown = 22%
تبي جلسة جديدة؟ نعم | لا

❌ فشل Walk-Forward
السبب: Win Rate = 43%
```

## زر تحرير مبلغ

```
الموظف يكمل عمله بالمبلغ الباقي
```

**مثال:**
```

        ↓

        ↓
الـ 600$ النقدي → رصيد محرر فوراً ✅
        ↓
صفقة A تقفل → الـ 300$ تروح للرصيد المحرر ✅
        ↓
وصلنا 900$ في الرصيد المحرر
(أكثر من 800$ المطلوبة)

الموظف يكمل بالباقي: 350$
```

```python
class WorkerBalance:
    worker_id: str
    total_capital: float      # كل الفلوس
    active_in_trades: float   # داخل صفقات مفتوحة
    free_cash: float          # نقدي حر
    
    @property
    def available(self):
        return self.free_cash  # المتاح للتداول


class ReleasedBalance:
    amount: float    # المبلغ المحرر
    # لا يلمسه أحد — لا يدخل في أي حساب

def release_amount(worker_id: str, amount: float):
    worker = get_worker(worker_id)
    
    # تقليص حصة الموظف فوراً
    worker.total_capital -= amount
    
    # النقدي الحر يروح للرصيد المحرر فوراً
    immediate = min(worker.free_cash, amount)
    released_balance.add(immediate)
    worker.free_cash -= immediate
    
    remaining = amount - immediate
    
    if remaining > 0:
        # الباقي ينتظر إغلاق الصفقات
        worker.pending_release += remaining
    
def on_trade_close(trade):
    worker = get_worker(trade.worker_id)
    

    if worker.pending_release > 0:
        # فلوس الصفقة تروح للرصيد المحرر
        to_release = min(trade.amount, worker.pending_release)
        released_balance.add(to_release)
        worker.pending_release -= to_release
        
        # الباقي يرجع للموظف
        worker.free_cash += (trade.amount - to_release)
    else:
        # لا يوجد تحرير — كل الفلوس ترجع للموظف
        worker.free_cash += trade.amount
```

# سيناريو الإيداع والسحب خارج الصقر
## شرح لـ Antigravity بالتفصيل

---

## القاعدة الأساسية

```
Binance لا يعرف شيء عن الصقر
بالنسبة له = رصيد واحد فقط

        ↓
أي إيداع أو سحب خارج الصقر
الصقر يكتشفه ويتصرف
```

---

## الإيداع — أودعت بالغلط أو بالعمد

```
أودعت 500$ في Binance مباشرة
        ↓
الصقر يكتشف الفرق خلال دقائق:
Binance: 9,500$ | الصقر: 9,000$
        ↓
الـ 500$ تروح للرصيد المحرر تلقائياً ✅
        ↓
من داخل الصقر أنت تقرر:
تحوّلها لموظف معين
أو تتركها في الرصيد المحرر
```

---

## السحب — سحبت بالغلط أو استعجلت


```
سحبت 1,000$ من Binance مباشرة
        ↓
الصقر يكتشف الفرق فوراً:
Binance: 8,000$ | الصقر: 9,000$
فرق: -1,000$
        ↓
تليجرام ينبهك:
"⚠️ رصيد Binance نقص 1,000$
الـ USDT الحر المتاح: 1,400$
من وين أخصمها؟"

1️⃣ من الرصيد المحرر
2️⃣ من موظف محدد
3️⃣ وزّع على الكل بالتساوي
```

---

## قاعدة الخصم

```
الصقر يخصم من USDT الحر فقط ✅
        ↓

لماذا؟
الصفقة القائمة = اشترى BTC بالفعل
الـ USDT راح وجاء BTC بدله
BTC محجوز في السوق — ما نلمسه

يعني:
USDT حر = نقدر نخصم منه ✅
BTC داخل صفقة = ما نلمسه ❌
```

---

## مثال كامل

```
الوضع:
عادي مستقر 1: 1,000$
  - داخل صفقات (BTC): 600$
  - USDT حر: 400$

عادي مستقر 2: 800$
  - داخل صفقات (BTC): 300$
  - USDT حر: 500$

رصيد محرر: 200$

إجمالي USDT الحر: 1,100$
        ↓
سحبت 800$ من Binance بالغلط
        ↓
تليجرام:
"⚠️ نقص 800$
USDT الحر المتاح: 1,100$
من وين أخصم؟"

اخترت: من الرصيد المحرر + موظف 1
200$ من الرصيد المحرر
600$ من USDT الحر لموظف 1
        ↓
النتيجة:
رصيد محرر: 0$
عادي مستقر 1: 400$ (يكمل بصفقاته القائمة)
عادي مستقر 2: 800$ (ما تأثر) ✅
```


```
Drawdown < 15%:

مثال: المحفظة نزلت من 1000$ لـ 870$ = 13% ✅

Win Rate > 50%:
أكثر من نصف الصفقات رابحة
مثال: 60 صفقة رابحة من 100 = 60% ✅
```

## من هو المستشار؟

```
الخبراء = أطباء يشخصون السوق
الموظفون = ممرضون ينفذون
المستشار = مدير المستشفى يراقب الكل
أنت = صاحب القرار النهائي
```

---

## الدور 1: الرقابي

### ماذا يراقب؟

**التسلسل:**
```
مثال:
الموظف حاول يدخل صفقة
قبل ما يمر على الطبقة 1
        ↓
المستشار يكتشف ✅

يبلغك فوراً على تليجرام:
"⚠️ عادي مستقر 1 تجاوز الطبقة 1"
```

**التناقضات:**
```
مثال:
قاعدة في الكود: "لا تدخل لما Fear&Greed > 75"
لكن الموظف دخل وهو 80
        ↓
المستشار يكتشف ✅
"⚠️ تناقض: عادي مستقر 2 دخل وFear&Greed = 80"
```

**التوقف:**
```
مثال:
موظف كان يشتغل — فجأة توقف
        ↓
المستشار يكتشف خلال دقيقة ✅
"⚠️ عادي متوتر 1 توقف فجأة — سبب غير معروف"
```

---

## الفكرة الأساسية

كل موظف مستقر عنده صديق متوتر واحد فقط.
الفلوس تتدفق بينهم أوتوماتيكياً حسب نوع السوق.
**الهدف: ما تنام أي فلوس بدون سبب.**

---

## قواعد الصداقة

```
عادي مستقر  ↔ عادي متوتر 

مطور مستقر  ↔ عادي متوتر 
مطور مستقر  ↔ مطور متوتر 


القواعد الثابتة:
✅ كل موظف = صديق واحد فقط
✅ لا يجوز موظف يصادق أكثر من موظف
✅ في حال عجبنا واحد ونبي نربطه مع ثنين . نستنسخه وهو يقوم بالواجب
```

---

## تدفق الفلوس — عند التبديل

### مثال: السوق تحوّل من مستقر إلى متوتر

```
عادي مستقر 1 — ميزانيته 1000$:
نقدي حر: 500$
صفقة A: 250$ (مفتوحة)
صفقة B: 150$ (مفتوحة)
صفقة C: 50$ (مفتوحة)
صفقة D: 50$ (مفتوحة)

عادي متوتر 1 — ميزانيته 0$ (ينتظر)
        ↓
السوق تحوّل متوتر ⚠️
        ↓
الـ 500$ النقدي الحر → تروح للمتوتر فوراً ✅
        ↓
صفقة A تقفل → الـ 250$ تروح للمتوتر فوراً ✅
صفقة B تقفل → الـ 150$ تروح للمتوتر فوراً ✅
صفقة C تقفل → الـ 50$ تروح للمتوتر فوراً ✅
صفقة D تقفل → الـ 50$ تروح للمتوتر فوراً ✅
        ↓
المتوتر يشتغل بكل فلوس تصله تدريجياً ✅
```

### العكس: السوق رجع مستقر

```
نفس المنطق بالعكس
فلوس المتوتر تنتقل للمستقر تدريجياً
```

## الحالة العرضية — بدون صديق

```
موظف مستقر بدون صديق متوتر:
→ ينهي صفقاته الحالية
→ يوقف عن الدخول الجديد
→ ينتظر حتى يُربط بصديق او يستقر السوق

موظف متوتر بدون صديق مستقر:
→ نفس الشيء تماماً
→ ينتظر بهدوء
```

## القناص — مستقل تماماً

## ما هو فحص السوق؟

قبل أي صفقة — الصقر يسأل سؤالاً واحداً:

## معايير التصنيف


### ATR (متوسط المدى الحقيقي):
```
ATR = كم يتحرك السعر في المتوسط

مثال BTC:
متوسط ATR الطبيعي = 500$
ATR الحالي = 800$
800 > 500 × 1.5 = 750
        ↓
السوق متوتر! ⚠️
```

### Volume (حجم التداول):
```
مثال:
متوسط Volume اليومي = 1,000,000$
Volume الحالي = 2,200,000$
2,200,000 > 1,000,000 × 2 = 2,000,000
        ↓
السوق متوتر! ⚠️
```

### القاعدة:
```python

def classify_market(symbol):
    atr_current = calculate_atr(symbol)
    atr_average = calculate_atr_average(symbol, days=20)
    
    volume_current = get_current_volume(symbol)
    volume_average = get_average_volume(symbol, days=20)
    
    if atr_current > atr_average * 1.5:
        return "volatile"  # متوتر
    
    if volume_current > volume_average * 2:
        return "volatile"  # متوتر
    
    return "stable"  # مستقر
```

```python
    "scalp": "1m",      # للقناص فقط — الصيد السريع
}

def should_enter(worker_type, symbol):
    # الخطوة 1: تحقق من الاتجاه العام
    trend = analyze_4h(symbol)
    if trend == "unclear":
        return False
    
    # الخطوة 2: ابحث عن نقطة الدخول
    entry_signal = analyze_15m(symbol)
    

    # الخطوة 3: للقناص فقط
    if worker_type == "sniper":
        return analyze_1m(symbol)
    
    return trend == "bullish" and entry_signal == "buy"
```

## المرحلة 1: اجتماع الخبراء

**ما هو؟**
8 نماذج AI تتناقش مع بعض لإنتاج استراتيجيات تداول.

**كيف يشتغل؟**
```
المالك يضغط زر "عقد الاجتماع" يدوياً
        ↓
Python يجمع البيانات (أسعار + أخبار + مشاعر)
        ↓
8 خبراء يتناقشون في 4 جولات
        ↓
الأمير يصدر 3 استراتيجيات فقط
```

**مثال:**
```

الاجتماع قرر:
استراتيجية محافظة: اشترِ BTC لما RSI < 35
استراتيجية متوسطة: اشترِ BTC لما RSI < 40
استراتيجية جريئة: اشترِ BTC لما RSI < 45
```

**قاعدة مهمة:**
اجتماع الخبراء **لا يتداول أبداً** — فقط يفكر ويقترح.

## المرحلة 2: الموظفون (Paper Trading)

**ما هو؟**
بوتات Python تختبر الاستراتيجيات بأموال وهمية على Alpaca Paper.

**كيف يشتغل؟**
```
الاستراتيجية المحافظة → موظف وهمي 1
الاستراتيجية المتوسطة → موظف وهمي 2
الاستراتيجية الجريئة  → موظف وهمي 3
        ↓
يشتغلون بأموال وهمية . مده لا نهائيه 
        ↓
النتائج تُحفظ في Supabase

```

**مثال:**
```
موظف وهمي 1: ربح 3% في شهر ✅
موظف وهمي 2: ربح 1% في شهر ✅
موظف وهمي 3: خسر 2% في شهر ❌
```

**قاعدة مهمة:**
الموظفون يشتغلون **أوتوماتيكياً** — لا تدخل يدوي.

```
☐ مستقر (stable) → يبني موظفين مستقر وهمي
```

**رأس المال الابتدائي:**
```
☐ 100$
☐ 1,000$
☐ مخصص .....$
```

**زاوية التفكير:**
```
☐ جديدة كلياً (new)
☐ تحسين الموجودة (improve) → تفتح قائمة موظفيك الحاليين
```

**نصيب الموظف من المحفظة:**
```
☐ مبلغ ثابت .....$
   مثال: 500$ ثابت دايماً
   المحفظة كبرت أو صغرت — الموظف يتداول 500$ دايماً

☐ نسبة .....% بدون Compounding
   مثال: 25% من 2000$ = 500$
   لو المحفظة صارت 2400$ → لا يزال يتداول 500$

☐ نسبة .....% مع Compounding
   مثال: 25% من 2000$ = 500$
   لو المحفظة صارت 2400$ → يتداول 600$
```

**حجم كل صفقة (= المخاطرة):**
```
☐ مبلغ ثابت .....$
   مثال: حصته 500$ — كل صفقة بـ 100$ ثابت دايماً

☐ نسبة من حصته .....%
   مثال: 20% من 500$ = 100$ لكل صفقة
   لو حصته كبرت لـ 600$ → كل صفقة 120$
```

**عدد الصفقات المفتوحة:**
```
☐ مفتوح بلا حد
   مثال: في 10 فرص → يدخل الـ 10 كلها بنفس الوقت

☐ حد أقصى ..... صفقة
   مثال: حد 3 صفقات
   في 5 فرص → يدخل 3 فقط وينتظر
   لما تقفل واحدة → يدخل الرابعة
```


**إعدادات السيولة:**
```
☐ صارم — التزم بالحجم المحدد فقط
   لو السيولة منخفضة → ينتظر ولا يدخل

☐ مرن — ادخل بالمتاح لو السيولة أقل
   مثال: طلب 1000$ والسيولة تسمح بـ 800$ → يدخل بـ 800$
   + ☐ استخدم الباقي في صفقات إضافية لو وجدت فرص
      الـ 200$ الباقية تدخل صفقة إضافية لو جاءت فرصة
```

**Take Profit:**
```
☐ كما في التوصية
   مثال: التوصيه الاساسيه قالت "اخرج لما الربح يوصل 3%"
   الموظف يلتزم بـ 3%

☐ نسبة مخصصة .....%
   مثال: بغض النظر عن التوصيه الاساسيه
   الموظف يخرج لما يربح 5%
```

**Stop Loss:**
```

☐ كما في التوصية + Trailing (الافتراضي)
   مثال: التوصيه الاساسيه قالت "اخرج لما الخسارة تصل 1%"
   + Trailing: لو السعر ارتفع → وقف الخسارة يرتفع معه تلقائياً

☐ نسبة مخصصة .....% + Trailing
   نفس الفكرة لكن بنسبتك أنت

☐ ثابت بنسبة .....% (بدون Trailing)
   وقف الخسارة ثابت عند نقطة معينة
   ما يتحرك حتى لو السعر ارتفع
```

**انتهاء الصلاحية:**
```
☐ كما في التوصية
   مثال: التوصيه الاساسيه قالت "الصفقة تنتهي بعد 48 ساعة"
   الموظف يلتزم . التوصيه قالت حتى الربح او الخساره ينتظر الموظف الربح والخساره

☐ اخرج بعد ..... دقيقة
   مثال: بعد 30 دقيقة بغض النظر عن الربح أو الخسارة
   الموظف يخرج بسعر السوق

☐ اخرج نهاية اليوم

   كل يوم الساعة 11:59 PM
   الموظف يغلق كل صفقاته المفتوحة
```

**ربط الصديق:**
